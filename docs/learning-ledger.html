html-playbook.html

html-playbook.html

A self-contained HTML meta-document that defines when and how to use HTML artifacts in a repo. Its thesis: HTML earns its place when the reader needs to see, compare, interact, or decide; otherwise markdown is sufficient. Also serves as the visual style template for any future HTML artifact in this project, including this learning ledger.

Key Findings
  • Entirely self-contained: inline CSS custom properties, no external deps — safe to copy the <style> block verbatim into other files.
  • Decision rule is binary: "visual / comparative / interactive / review pressure" → HTML; otherwise → markdown. The SVG diagram encodes this as a flowchart.
  • "HTML is a reader surface, not a source of truth" — durable decisions distill back to .md files (AGENTS.md, STRATEGY.md, CONTEXT.md, ADRs).
  • Chooser uses aria-pressed buttons — accessibility-friendly alternative to <select> worth reusing.
  • Copy buttons use navigator.clipboard.writeText() with 1200ms reset — minimal, no library needed.
  • References "Sandcastle output" — a project-specific tool not explained anywhere in the file.
